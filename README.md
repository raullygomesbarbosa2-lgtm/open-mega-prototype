# Open Mega Prototype (0.2)

An independent Android research prototype, built from scratch. This is **not a playable Mega Drive emulator** and does not reuse or include a commercial emulator core or Libretro.

## Distribution and privacy
The app is native Android Java (no WebView or web wrapper), free to use, with no payment, subscription, paywall, or paid features. No ads or analytics are included. ROM files are selected through Android's document picker and are not uploaded by this app.

## UI implemented
- Neon-green research-deck interface with switchable accent themes, glow/grid styling, generated abstract local-ROM cards, a searchable library, and a local document picker.
- Recognizes local `.bin`, `.gen`, `.md` and `.smd` files; selected file is read for diagnostics (up to 32 MiB). No ROMs or copyrighted cover art are bundled. The abstract art is generated by the app and is not represented as an accurate game cover.
- On-screen joystick and A/B/X/Y controls animate on touch for visual demonstration only.
- Java Android app, min SDK 19 (Android 4.4); no WebView or third-party emulator core.

## Accurate limitations
The project contains only a tiny, nonfunctional 68000 instruction subset. It has no Mega Drive VDP / graphics or audio emulation, no controller hardware input path, and no game compatibility. ROM selection is for local-file research/diagnostic UI only; loading a ROM does not make a game playable. Touch controls do **not** drive emulated hardware. The screen does not show game video or produce game audio. No BIOS or ROM is bundled.

## Build
GitHub Actions builds a debug APK with Gradle and uploads it as `open-mega-prototype-debug`. This is a UI/CPU-subset research prototype, not an emulator. Install APKs only from a build you trust; debug APKs are unsigned for store distribution.
